# Ethical Boundaries

This project is for authorized security work only.

Rules:

- Only test systems you own or have explicit permission to assess.
- Always define scope before testing.
- Do not access, copy, modify or delete private data.
- Do not perform denial-of-service testing.
- Do not run aggressive automated scans without permission.
- Do not bypass authentication unless explicitly allowed.
- Do not publish sensitive findings without responsible disclosure.
- Document everything clearly and respectfully.

If there is no permission, there is no test.
